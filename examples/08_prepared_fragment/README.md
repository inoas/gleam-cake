# Cake demo app: Fragment with Prepared Statement

This demo of Cake shows how to run a fragment with a prepared
statement.

To start 🐘PostgreSQL via docker compose, see
[examples/README.md](../README.md#Installing-prerequisites), then:

```shell
gleam clean
gleam run
```
